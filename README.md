\## ⚡ What is DropBoard?



DropBoard is a complete dropshipping automation platform that:



\- \*\*Syncs Orders\*\* - Automatically from Shopify, TikTok Shop, Facebook, etc.

\- \*\*Processes Payments\*\* - Via Stripe, PayPal, and more

\- \*\*Fulfills Orders\*\* - Auto-ships via Printful, Spocket, or custom suppliers

\- \*\*Tracks Shipments\*\* - Real-time tracking updates to customers

\- \*\*Sends Notifications\*\* - Automated emails for orders, shipments, updates

\- \*\*Manages Inventory\*\* - Real-time stock levels across channels

\- \*\*Calculates Profit\*\* - Per-order, per-product financial tracking

\- \*\*Provides Analytics\*\* - Revenue, conversion rates, customer insights



\*\*All automated. All in one place. No coding required.\*\*

\## 🚀 Quick Start



\### Prerequisites

\- Node.js 16+ installed

\- npm or yarn package manager

\- Modern web browser



\### Installation



```bash

\# Clone repository

git clone https://github.com/yourusername/dropboard.git

cd dropboard



\# Install dependencies

npm install



\# Create environment file

cp .env.example .env



\# Start development server

npm run dev

```



Visit `http://localhost:3000` and sign up!



\## 📋 Setup Guide



\### Step 1: Create Your Account

1\. Visit the dashboard

2\. Click "Sign Up"

3\. Enter your store name, email, password

4\. ✅ Account created!



\### Step 2: Connect Shopify (5 minutes)

1\. Go to \*\*Integrations\*\* → \*\*Shopify\*\*

2\. Follow setup instructions

3\. Copy Access Token from Shopify

4\. Paste and save

5\. ✅ Orders will auto-sync!



\### Step 3: Add Suppliers (3 minutes)

1\. Go to \*\*Integrations\*\* → \*\*Printful\*\* (or Spocket)

2\. Copy API Key

3\. Paste and save

4\. ✅ Ready to fulfill orders!



\### Step 4: Set Up Payments (5 minutes)

1\. Go to \*\*Integrations\*\* → \*\*Stripe\*\*

2\. Copy API Keys from Stripe

3\. Paste and save

4\. ✅ Accept payments from customers!



\### Step 5: Add Your First Product

1\. Go to \*\*Products\*\* → \*\*Add Product\*\*

2\. Fill in product details

3\. Set price and cost

4\. ✅ Product is live!



\### Step 6: Drive Traffic

1\. Create content on TikTok/Instagram

2\. Run Facebook ads ($5-10/day)

3\. Share with email list

4\. ✅ Get your first customers!

\## 🐛 Troubleshooting



\### "Module not found: '@/lib/auth'"

\- Make sure you created `lib/auth.js` file

\- Run `npm run dev` again



\### Orders not syncing

\- Check Shopify API token is correct

\- Verify API scopes are enabled

\- Test connection in Integrations page



\### Payments not processing

\- Verify Stripe keys are correct (live keys, not test)

\- Check Stripe account status

\- Contact Stripe support if issue persists



See \[Help page](./app/help/page.jsx) for more troubleshooting!
